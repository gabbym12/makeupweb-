# Running GlamLab Studio on Replit

This is a static HTML, CSS, and JavaScript app. It has no package-install step or backend.

- The `Start application` workflow serves the project on port 5000.
- Open the root URL to reach the home page; signed-out visitors are redirected to `login.html`.
- Sign-up and login data are stored in the browser's `localStorage`.
- To run it from a shell, use `python3 -m http.server 5000 --bind 0.0.0.0`.
